# Changelog

## 0.1.51 - first public beta

First public release. Main features:

- OpenXR VR rendering for MIMESIS (Direct3D 11), automatic start when a headset is connected, F11 to switch, flat mode otherwise.
- Motion controls: stick walking, snap / smooth turning, room-scale walking.
- The character's own arms and fingers follow the controllers; items sit in the hand; hands stop at walls.
- Melee by swinging the arm, within the game's own timing (no faster hits than with the button); vibration feedback.
- Wrist interface: inventory on the left wrist (touch to select), health / contamination / stamina watch on the right arm.
- Emote wheel on Y, button remapping with a layout view, controller buttons in the game's prompts.
- Monitor view for streaming with the wrist interface in the screen corners.
- Settings panel on the wrist and under Settings → VR in the game menu (also without a headset).
- Performance options and presets for weaker PCs.
- Languages: English, Russian, Korean (machine translation); more languages through text files.
- Installation by hand or with a Thunderstore mod manager (r2modman, Gale).
- "Debug tools" setting hides diagnostics, cheats (host only) and developer hotkeys from normal play.

Development builds 1-50 were internal; their notes are in the repository history.
